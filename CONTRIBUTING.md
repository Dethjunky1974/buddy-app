# Contributing to Buddy

Thanks for helping make Buddy easier to use. Open an issue for bugs or feature ideas, and include your macOS version, Node version, and steps to reproduce. Do not post vault notes, terminal transcripts, credentials, or private repository URLs in public issues.

For code changes, use a small branch and describe the user-facing behavior. Run `npm test` and check the app locally with both CLI panes before opening a pull request. Keep vault operations scoped: Buddy must never force-push, reset, or commit unrelated files.
